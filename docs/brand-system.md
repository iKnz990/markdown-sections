# Brand System

Nocturnal Markdown Sections should feel like repair infrastructure, not a generic Markdown package.

## Position

Safe Markdown edits for agents.

`nocturnal/markdown-sections` gives PHP applications a bounded editing surface inside Markdown. It parses named sections, validates primitive contracts, previews exact diffs, and rejects stale edits before anything touches the source file.

## Promise

Untouched Markdown stays untouched.

## Mechanism

Give the agent one section, one contract, one diff, one checksum gate.

## Voice

Use:

- Safe edits. Exact patches. No whole-file rewrites.
- Markdown is readable. Broad rewrites are dangerous.
- Agents get a manifest, not the source file.
- Rendering is optional. Source safety is the point.
- Patch first. Diff first. Checksum first.

Avoid:

- AI-powered Markdown magic.
- Supercharge your content.
- Effortlessly transform Markdown.
- Beautiful Markdown components.
- Revolutionary parser.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Void | `#050505` | primary background |
| Charcoal | `#0F0F0F` | panels and code blocks |
| Graphite | `#1A1A1A` | borders and inactive surfaces |
| Iron | `#262626` | dividers and table borders |
| Ember | `#990001` | accent, selected span, gate states |
| Signal Red | `#B00000` | active patch line |
| Burnt Amber | `#D87A22` | warnings and stale states |
| Silver | `#B3B3B3` | secondary text |
| Muted Gray | `#737373` | metadata |
| Bone | `#F2F0EA` | primary text |
| Pass Green | `#2E7D4F` | limited pass states |

Do not use Ember or Signal Red as small body text on black.
